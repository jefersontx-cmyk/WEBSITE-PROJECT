# SPORTS RAIN

Este proyecto es una tienda web de equipación deportiva creada con HTML, CSS y JavaScript. Tiene un diseño moderno y oscuro, con secciones de catálogo, historia de la marca y navegación adaptada.

## Descripción del proyecto

- Página principal con buscador de productos, hero destacado y accesos a las secciones principales.
- Página de historia que narra los valores, misión y logros de la marca.
- Catálogo de productos dinámico en JavaScript para tacos, equipación y accesorios.
- Carrito funcional y experiencia de usuario mejorada.

## Plantillas Bootstrap de referencia

Este sitio sigue una estética y estructura similar a las siguientes plantillas Bootstrap:

- **Shop Homepage** (Start Bootstrap)
  - Estilo de tienda moderna con hero principal, celdas de productos y navegación simple.
- **Agency** (Start Bootstrap)
  - Diseño de landing page con secciones de servicios, llamada a la acción y bloques de contenido diferenciados.
- **Creative** (Start Bootstrap)
  - Página de presentación elegante con bloques de texto y contenido visual sobre fondo oscuro.
- **Freelancer** (Start Bootstrap)
  - Estructura de sitio web personal o comercial con secciones de información resaltadas y botones de acción.

## Notas

Aunque el proyecto está hecho con CSS personalizado, estas plantillas sirven como apoyo para la organización y la apariencia general del sitio.
